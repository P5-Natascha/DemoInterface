So kommt dein Daumen ans Auto

Browser können keine UDP- oder TCP-Verbindungen öffnen. Deshalb vermittelt ein fester Server zwischen Website und Auto.

1

Joystick

Der Browser berechnet X und Y als Werte von 0 bis 4095, genau wie der Analogstick der Fernbedienung.

2

WebSocket

Die Werte gehen etwa 30-mal pro Sekunde an den Server.

3

UDP und TCP

Der Server sendet die Joystickdaten per UDP (Port 9005) und empfängt Sensordaten per TCP (Port 9006).

4

Auto

Der ESP32 wertet die Daten aus und steuert Motor und Lenkung.

Das Projekt

Hier ist Platz für die Geschichte hinter dem Auto. Die Eckdaten stehen schon, den Rest füllen wir später.

SteuerungAnaloger Joystick, 12 Bit
JoystickdatenUDP, 2 × uint16
SensordatenTCP, Textzeilen
MesswerteAkku, Strom, Lenkung, Abstand
Sicherheit: Wenn länger als eine halbe Sekunde keine Eingabe ankommt, sendet der Server den Joystick in Mittelstellung.
